Quick Start

  1. Open the emulator in your browser.
  2. Select an ISA from the dropdown (default: Intel 8086).
  3. Write assembly in the editor, or click Example to load a sample program.
  4. Press F7 or click Assemble to compile and load.
  5. Press F8 or click Step to execute one instruction at a time.
  6. Press F5 or click Run to execute continuously until HLT.
  7. Switch to the Registers tab to watch register values change in real time.
Tip: Your source code is auto-saved to the browser's localStorage. Press Ctrl+S to save manually. A Share button copies a URL with your code encoded in it.

Supported ISAs

16-bit

Intel 8086

16-bit x86 with segmented memory (CS:DS:ES:SS). DOS INT 21h and BIOS INT 10h subset. 1 MiB address space. COM-format entry at 0x100.

8-bit

Intel 8085

8-bit accumulator architecture. Full ISA including SIM/RIM, DAA, and hardware interrupts (TRAP, RST 7.5/6.5/5.5, INTR). SID/SOD pins.

8-bit

Intel 8051 (MCS-51)

8-bit MCU with SFRs, 4 register banks, bit-addressable RAM, Timer 0/1, serial port, and 5 interrupt sources (INT0/INT1, TF0/TF1, serial).

8-bit

MOS 6502

8-bit with zero-page fast access, hardware stack at 0x0100, decimal mode, indexed addressing. BRK/RTI interrupt model.

8-bit

Zilog Z80

Full 8080 superset plus IX/IY index registers, shadow registers (A'F'/BC'/DE'/HL'), block transfers (LDIR/LDDR), bit instructions, IM 0/1/2.

32-bit

RISC-V RV32I

32-bit base integer ISA with M extension (MUL/DIV/REM), CSR instructions, ECALL semihosting (write/exit). Flat 1 MiB address space.

Assembly Syntax

All assemblers share a common line-oriented, case-insensitive syntax. ; starts a comment. Labels are defined with name: or name EQU expr.

Number Formats

FormatExampleMeaning
Decimal42Base 10
Hex (prefix)0x2ABase 16
Hex (suffix)2AhBase 16
Binary10101bBase 2
Octal52qBase 8
Character'A'ASCII value (65)

Directives

DirectiveSyntaxDescription
ORGORG 100hSet the origin address for assembled code
DBDB 'Hello',0Define byte(s)
DWDW 1234hDefine word (16-bit, little-endian)
EQUPORTA EQU 0FFhDefine a constant symbol
ENDENDMark end of source (optional)

8086-Specific Syntax

ORG 100h
MOV AX, OFFSET msg     ; direct addressing
MOV BX, [SI+4]         ; indexed addressing
ADD AX, BX             ; register-to-register
PUSH DS                ; push segment register
INT 21h                ; DOS service call
msg DB 'Hello$'        ; $-terminated string

8085-Specific Syntax

MVI A, 41h             ; load immediate
LXI H, 2000h           ; load register pair
MOV B, M               ; load from memory via HL
OUT 01h                ; output to port 01h
RST 7.5                ; restart interrupt

8051-Specific Syntax

MOV A, #41h            ; load accumulator (immediate)
MOV SBUF, A            ; transmit via serial port
SJMP $                 ; spin loop
SETB P1.0              ; set port bit
CJNE A, #0FFh, loop    ; compare and jump if not equal

Z80-Specific Syntax

LD A, 41h              ; load accumulator
LD BC, 1000h           ; load register pair
ADD A, B               ; add register to accumulator
OUT (1), A             ; output to port
IM 1                   ; set interrupt mode 1
LDIR                   ; block copy (DE←HL, BC count)

6502-Specific Syntax

LDA #41                ; load accumulator immediate
STA $0200              ; store to absolute address
LDX #10                ; load X index
INX                    ; increment X
BNE loop               ; branch if not zero
BRK                    ; software interrupt

RISC-V RV32I Syntax

ADDI x1, x0, 42        ; x1 = 42
LW   x2, 0(x1)         ; load word from memory
SW   x2, 4(x1)         ; store word to memory
BEQ  x1, x2, label     ; branch if equal
ECALL                  ; environment call (semihosting)

The emulator includes simulated hardware devices accessible via I/O ports. Click the Devices tab to see them, or pop them out as floating windows by clicking the float icon.

ISA-Specific Ports: 8086 uses INT 21h / INT 10h for I/O. 8085 uses OUT 01h for character output. 8051 writes to SBUF for serial output. 6502 writes to port $01. Z80 uses OUT (1),A.

Debugging Features

Time-Travel Debugging

Every step automatically saves a snapshot. Click Back to undo the last instruction and restore the previous CPU state. This works for as long as you have history (up to 200 steps).

Breakpoints

  • Click a disassembly line to toggle an unconditional breakpoint.
  • Shift+click to set a conditional breakpoint with an expression.
  • Double-click to run-to-cursor.

Conditional Breakpoint Expressions

ExpressionDescription
CX==0Break when CX equals 0
AX>10Break when AX is greater than 10
mem[0x200]==5Break when memory at 0x200 equals 5
IP==0x100Break when IP reaches 0x100

Watch Expressions

Switch to the Watch tab to monitor registers or memory locations in real time. Type a register name (e.g. AX) or memory expression (e.g. [0x200]) and press +. Values that change between steps are highlighted in amber.

Snapshot Save/Load

Click Save to download a binary snapshot of the entire CPU state (registers, flags, memory, breakpoints, watch expressions). Click Load to restore a previously saved snapshot. Snapshots are backward-compatible — old format files load fine.

Share Links

Click Share to copy a URL with your source code, breakpoints, and watch expressions encoded in it. Anyone with the link can open the same program in their browser.

Building from Source

Prerequisites

  • Rust (with wasm32-unknown-unknown target)
  • wasm-pack: cargo install wasm-pack

Commands

# Add the WASM target (once)
rustup target add wasm32-unknown-unknown

# Build the WASM package
wasm-pack build --target web --out-dir docs/pkg --release --features wasm

# Run native tests (all 6 ISAs)
cargo test

# Lint
cargo clippy --all-targets

# Serve the web demo locally
python3 -m http.server -d docs 8000
# Then open http://localhost:8000

CLI Runner (headless)

cargo run --example run -- examples/hello.asm          # 8086
cargo run --example run -- --isa 8085 examples/hello85.asm
cargo run --example run -- --isa 8051 examples/hello51.asm
cargo run --example run -- --isa z80 examples/helloz80.asm
cargo run --example run -- --isa 6502 examples/hello6502.asm
cargo run --example run -- --isa rv32 examples/hellorv32.asm

# 8086api.md — Multi-CPU (`8086emu@1.6.0`) API + OpenHW gap spec

Probed live from this repo (`docs/pkg/multi_cpu_emu.js`, `docs/pkg/multi_cpu_emu.d.ts`,
`docs/pkg/package.json`, `README.md`, `src/wasm.rs`) for npm `8086emu@1.6.0`
(24/24 smoke checks pass — all 6 ISAs, board helpers, LUI, snapshot/restore;
plus circuit-board hook checks: ppi_set_input GPIO-in, per-ISA cycles, Z80
USART / 6502 ACIA Rx, 8051 usart_rx alias, rv32 GPIO; plus real-Worker proofs:
use-before-init reproduces the exact `__wbindgen_malloc` TypeError, init-first
constructs cleanly in Node workers and browser Web Workers).
One Rust crate (`multi-cpu-emu` 1.6.0), six ISAs, one wasm-bindgen module.

(`Object.getOwnPropertyNames(Emulator.prototype)`, sorted).

## 2. Init (Node needs the module bytes — verified)

```js
import init, { Emulator, initSync } from './multi_cpu_emu.js';
import { readFileSync } from 'fs';
initSync({ module: readFileSync('./multi_cpu_emu_bg.wasm') }); // Node
// await init(); // browser only — bare default() does fetch() and FAILS in Node ("fetch failed", verified)
const emu = new Emulator("8086"); // "8086" ("8088" = same core) | "8085" | "8051" | "6502" | "Z80" | "rv32" (else throws)
```

### Worker init contract (read this before filing "dies in worker" bugs)

Every `Emulator` method touches `wasm.__wbindgen_malloc`, which only exists
after init resolves. Constructing first dies with `TypeError: Cannot read
properties of undefined (reading '__wbindgen_malloc')` — proven byte-identical
in a Node `worker_threads` repro, and proven clean with init-first in both
Node workers and real browser `Worker`s (GPIO-in + RX-echo green, zero page
errors). Rules:

- Each `Worker` owns a separate WASM instance: init **inside** the worker,
  before the first `new Emulator(...)`. Init on the main thread does not
  cover workers.
- Browser / bundler worker: `import init, { Emulator } from '8086emu';`
  then `await init();` as the first statement (bare `init()` fetches the
  sibling `.wasm` relative to the glue URL — keep the three published files
  together).
- Node worker: `initSync({ module: <bytes> })` synchronously before first use.
- `typeof emu.ppi_set_input === 'function'` is the 1.6.0 feature probe the
  runner already gates on; `undefined` means the bundle is ≤1.5.1.

Semantics (`.d.ts` + README + `src/wasm.rs`, condensed):

- Assemble: `assemble(source)->Uint8Array` (throws on error), `assemble_info(source)->string[]`
  (`ADDR  BYTES` per line), `disasm(addr,count)->string[]` ("ADDR  BYTES  text").
- Load/run: `load(code, origin)` (writes memory + sets PC), `load_rom(data, addr)` (read-only
  image; 8051→XDATA when EA low), `set_pc(addr)`, `set_reg(name, val)` (names the ISA exposes;
  unknown names ignored), `run(max_steps)->steps`, `run_to(target,max)->steps` (target NOT
  executed), `run_bp(max,bps:Uint32Array)->steps` (bps NOT executed), `step()`,
  `reset()` (regs/flags/PC, memory preserved), `halted()->bool`.
- State: `pc()->u32`, `regs()->"NAME=value"[]` (4-digit hex; rv32 prints 8 digits),
  `flags()->("CF"|"ZF"|"SF"|"PF"|"AF"|"OF"|"DF"|"IF"|"TF")[]` (8086 naming for every
  ISA — the IDE's FLAG_MAP relabels per ISA, e.g. 8085 CY/Z/S/P/AC/IE),
  `cycles()->bigint` (u64 clock on ALL six ISAs: machine cycles/T-states for
  8086/8085/8051, nominal per-instruction tables for 6502/Z80, single-cycle
  for rv32; feeds timers + host sim-time), `mem(addr,len)->Uint8Array`,
  `mem_write(addr,data)` (IDE poking; invalidates the decode cache), `snapshot()->Uint8Array` /
  `restore(bytes)` (deterministic time-travel / step-back), `out()->string` (drains the
  program-output buffer).
- Output conventions: 8086 = `INT 21h` file/char services (AH 01/02/06/07/08/09/0A/0C,
  3C-42 file ops, 2A/2C clock) + `INT 10h` AH 0E (+ `OUT 01h` prints AL, USART `50h`
  also echoes); 8085 = `OUT 01h` prints A (+ USART `50h` echoes); 8051 = SBUF write;
  6502 = `STA` to `$01` (also `$F001`) prints A (+ ACIA `STA $5000` echoes);
  Z80 = `OUT (n),A`/`OUT (C),r` to port `01h` prints (+ USART `OUT (50h)` echoes);
  rv32 = `ECALL` semihosting (a7=64 write fd/a1/a2, a7=93 exit; `EBREAK` halts)
  (+ board UART `SB` to `0xF0000` echoes).
- IO/ports: 8085/8086 `port_write(port 0-255, val)` / `port_read(port)`; 8051 `port_write` = P0–P3 pins;
  8086 `pit_count(n 0..2)`, `speaker()->0|1` + `speaker_ctrl()->byte` (port `61h` gate+enable AND
  PIT ch2 OUT); 8085 `set_sid(bool)` / `sod()->0|1` (SIM/RIM serial pins); 8051 `serial_rx(ch)`
  (SBUF+RI), `sfr(addr)->byte` / `set_sfr(addr,v)` (SFR/IRAM editor), `set_ea(bool)` +
  `ea_active()` + `ext_code_region()`; Z80 `set_interrupt_mode(0/1→0x0038, 2→I*0x100+data)` +
  `ctc_pulse(ch)->0|1` / `ctc_count(ch)` (CTC channels at ports `10h`–`13h`) + kit USART
  at `50h`/`51h` (firmware `IN`/`OUT`, host `usart_rx`/`usart_status`); 6502
  `via_read/via_write(rs 0-15)` + `via_irq()->0|1` + `via_handshake(line 0=CA1/1=CB1, high)`
  (6522 VIA at `$6000`) + board ACIA at `$5000`–`$5003` (`LDA`/`STA`, host
  `usart_rx`/`usart_status`; debugger `mem()`/disasm peek without consuming);
  rv32 board UART+GPIO at `0xF0000`–`0xF0003` (`LB`/`SB`; host `port_write(0xE0)` =
  pin inject, `port_read(0xE0/0xE1)` = DATA/DIR); 8086 `push_key(ch)` + `waiting_input()` (INT 21h keyboard block),
  `cursor()->[col,row]`, `screen()->Uint8Array` (80×25 char/attr @0xB8000, else []),
  `video_mode()->n` (13h = pixel gfx), `gfx()->GfxInfo|undefined`.
- GPIO input without clobbering outputs: 8086/8085 `ppi_set_input(0xE0/0xE1/0xE2=A/B/C, v)`
  drives the 8255 external-input latch (input-mode bits read pins, output-mode bits
  keep the latch; snapshot-covered). `usart_rx(v)` is the universal serial-RX inject
  for every ISA (USART/ACIA/SBUF/board-UART); `usart_status()` reports
  TxRDY/RxRDY/TxEMPTY in one bit layout (8051 mapped from SCON).
- Memory map: `set_rom_region(base,len)` + `rom_region()->[base,len]|undefined` (8086/8085;
  also rv32/6502/Z80 report it, 8051 returns none; 8051 uses `set_ea`/`ext_code_region` instead);
  `set_sram(base,len)` (8085 ext SRAM, def 8K@0x9000) + `sram_region()`; `set_flash(base,len)` +
  `load_flash(data,addr)` + `flash_region()` (8086 default 64K@0xE0000, 8085 8K@0xA000);
  `fs_put(name,data)` / `fs_get(name)->bytes|undefined` (8086 DOS VFS preload/readback).
- Interrupts/clock: `interrupt(kind,data)` (8086: NMI/INTR+vector; 8085: TRAP/RST75/RST65/RST55/INTR+vector;
  8051: INT0/INT1; 6502: NMI/else IRQ; Z80: NMI/else INT; rv32: throws), `set_clock(y,mo,d,h,mi,s)`
  (INT 21h 2Ah/2Ch, INT 1Ah).
- Device kit: `ppi()->[PA,PB,PC,ctrl]|undefined` (8255 @`E0h`–`E3h`), `adc_set/adc_get(ch)`
  (ADC0808 `28h`/`29h`), `lcd_text()->[line0,line1]|undefined` (HD44780 `38h`/`39h`),
  `rtc_reg(reg)` + `rtc_write(reg,val)` (CMOS `70h`/`71h`), `dma_status()` (8237),
  `usart_status()/usart_rx(v)` (8251 `50h`/`51h`), `kb_disp()/kb_push(k)` (8279 `68h`/`69h`),
  `i2c_write/i2c_read` + `i2c_dump()->bytes|undefined` (8051 24C02 image),
  `spi_write/spi_read` (8051 W25Q Flash).
- Board helpers: `mem_size()->bytes` (addressable memory per ISA — no hardcoding),
  `via_pins(port,v)` (drive 6502 VIA port A/B inputs from circuit pins).
- `GfxInfo { base, w, h, free() }` — pixel framebuffer descriptor (base = linear addr).

`cargo run --example run -- [--isa 8086|8088|8085|8051|6502|Z80|rv32] [--max-steps N] [--verbose] [--grade spec] [--bench [N]] file.asm` — prints regs/flags/output.

`hello6502.asm` (`STA $01`), `helloz80.asm` (`OUT (1),A`), `hellorv32.asm` (ECALL),

## 5. OpenHW gap (what's missing today — green-field family)

- Nothing exists: no board component (`openhw-8086`-style), no `LOGIC_REGISTRY`/`COMPONENT_PINS` keys, no `board-profiles.ts` pins, no `backend/src/compiler/boardRegistry.js` entry (only uno+pico), no runner branch in `execute.ts` (pico→RP2040 else AVR), no `runners/*8086*`.
- Closest analogues: AVRRunner (8-bit, ports, `port_read/write`-shaped IO) for 8085/8051/6502/Z80; RP2040Runner (memory map + UF2/ELF load + GDBServer) for 8086/rv32. 8086 DOS VFS + text framebuffer + PIT are new UI surfaces (console + memory dump + SFR/memory-map panels already exist in the package's own IDE — reusable as reference).
- Good news: `assemble()` in-WASM removes the backend compiler dependency for asm teaching flows; `snapshot/restore` + `run_bp/run_to` map 1:1 onto the debug service (HALT/STEP/breakpoints) without extra work.

## 6. Runner mapping checklist (BoardRunner `component-registry.ts:472-501`)

1. Load: `new Emulator(isa)` per board variant; `assemble(src)` (editor) or `load(code,origin)` / `load_rom(image,addr)` (+`set_sram`/`set_ea`/`set_rom_region` where applicable); `set_pc`; `reset()`.
2. Tick: `run(budget)` per frame (NOT per-instruction — wasm boundary ~100-300ns/call); `step()` for debug STEP; `halted()/waiting_input()` → stopped/blocked; `pc/regs/flags/cycles` → debug snapshot + sim-time (`cycles` T-states, not wall clock).
3. GPIO/ports: `port_write/port_read` (8085/8086) + 8051 P0–P3/sfr + SID/SOD/serial_rx ↔ `propagateBoardPin`/ComponentSignalAPI (`onPinStateChange`, UART/LED/7-seg/switch components); PIT channels via `pit_count` → timer/PWM components.
4. UART/console: `out()` drain → serial TX frames; `push_key` (8086) / `serial_rx` (8051) ← `serialRx/serialRxByte`; `set_clock` ← board RTC options; baud = record-only (`setSerialBaudRate` passthrough).
5. Display/mem: `screen()` (text) + `gfx()` (pixel, base/w/h → existing VRAM SAB path, keep MessagePort zero-copy) → display descriptors; `mem/mem_write` → READ_MEM/WRITE_MEM; `fs_put/fs_get` → file-injection UI.
6. Debug: `run_bp/run_to` → PC breakpoints at chunk boundary; `snapshot/restore` → step-back/record-replay; `sfr/set_sfr`, `set_reg`, `disasm/assemble_info/cursor`, `rom/sram/ext_code_region` → memory-map + register panels; `interrupt()` ← fault/test injection.
7. SAB publish: console/pin/LED state via `uiState` slots in `forceEmitState`; `interrupt`/VFS/snapshots stay on postMessage (infrequent, must-not-lose).
